# Aditya Biswas — Portfolio '25

A modern, high-performance, and immersive frontend portfolio crafted for **Aditya Biswas** (Full-Stack Developer & UI/UX Craftsman).

## 🚀 Technologies Used

- **React 19 + Vite**: Modern, ultra-fast frontend architecture
- **GSAP + ScrollTrigger**: Scroll-based timelines, vector parallax, pinning, and synchronized motion
- **Lenis**: Buttery smooth scroll engine integrated directly with GSAP's ticker
- **Tailwind CSS v4**: Responsive, glassmorphic, and minimal design system
- **JavaScript (ES6+)**: Interactive logic, reactive state flows, and micro-interactions
